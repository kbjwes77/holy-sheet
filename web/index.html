The Test JSON format

A test is a short text file with a name and a list of questions. You rarely need to write one by hand: an AI chatbot can, and the editor's checker tells you in plain words if anything is off. 

{
  "test": "Unit 4 Quiz",
  "type": "Quiz",
  "questions": [
    {
      "prompt": "Which of these is a prime number?",
      "choices": ["9", "15", "17", "21"],
      "answer": "C",
      "explanation": "17 has no divisors other than 1 and itself."
    },
    {
      "type": "Free Response",
      "prompt": "Explain why the sky is blue.",
      "answer": "Air scatters short (blue) wavelengths of sunlight the most."
    }
  ]
}
  • Required: test (the name) and questions. Each question needs a prompt and its choices (2 to 8).
  • Optional but useful: answer on every question, which gives you the answer key and lets Grade Sheets score the test.
  • Don't type letters or numbers into choices or prompt: the sheet adds "A)", "B)" and the question number itself.
  • Use straight quotes ("), no trailing commas, and keep every { and [ closed.
Every option
  • test: the test name (required).
  • type (optional): "Study Guide", "Quiz" or "Exam". Quizzes and exams print and grade the same way. Without a type, a sheet whose questions have no choices and no answer is a study guide; everything else is a quiz. A study guide prints its questions without choice rings or writing boxes, and may keep choices, answer and explanation for its solutions.
  • questions: 1–256 questions, each with a prompt and 2–8 choices (lettered A–H). A study guide question may omit its choices.
  • answer (optional): the correct letters, e.g. "B" or "AC" for more than one. Give it for every question or none; with all of them you get the grader's answer key.
  • type (optional): "Multiple Choice" (the default) or "Free Response". A free-response question has no choices; students write in a full-width box instead. Its answer is the model answer the grader compares theirs with, so every question then needs an answer. It may also have a rubric (what earns each point) and lines (writing lines, 1–20, default 3).
  • explanation (optional): why the answer is correct, shown with it in a study guide's solutions and in a Teacher's Copy. It prints in the sheet's font.
  • points (optional): what the question is worth, a whole number from 1 to 100 (default 1).
  • figures (optional, in a question): ids of figures to print between the prompt and the choices, side by side while they fit.
  • Teacher's Copy (a Sheet layout option): prints the sheet as an ungraded study guide with solutions inline. Each multiple-choice question's correct choices are filled in, and each free-response question prints its answer, with its explanation under either when Include explanations is on. Every question needs an answer.
  • No other keys are allowed. A sheet can be at most 16 pages.
Symbols that can't be printed (Greek letters, arrows, math)

The sheet prints in a standard PDF font, so text can only use letters and symbols that font has. Anything else is reported as an error naming the character and the question, e.g. Contains "Δ" (U+0394), which can't be printed with the sheet's font. This covers the test name, instructions, prompts, choices, captions and, on a study guide or Teacher's Copy, answers and explanations.

  • Works: letters, digits and keyboard punctuation, accented Latin letters, and these symbols: ° ± × ÷ ² ³ ¼ ½ ¾ µ ¢ £ € § ¶ © ® ™ « » ¿ • – — … ‘ ’ “ ”
  • Doesn't work: Greek letters (Δ θ π Σ), arrows (→), math symbols (≤ ≥ ≠ ≈ √ ∞ ∑ ∫), superscripts and subscripts beyond ² ³ (⁴ ₂), and emoji.
  • Instead: spell them out (delta x, pi, ->, <=, x^4, H2O), or draw the expression in an SVG figure, which can show any shape you can draw (but its text must still use Arial, Times or Courier).
How questions are laid out on the page

Questions print in two 3.3 in columns, down the left and then the right. A question prints full width when one of its choices would wrap in a column or a figure is wider than one. A grey line across the page separates the columns from full-width questions below them; after a full-width question below the columns, the rest of that page prints full width. If a full-width question's figures are each 3.3 in or narrower, they print to the right of its text when that's shorter and no choice wraps. Keep choices short to fit more on a page.

Figures: graphs, diagrams and tables

Define each figure once in a top-level figures object, usually at the end of the file, keyed by an id (letters, digits, - and _). Several questions can show the same figure.

  • type: "svg" for a drawing or graph, or "table" for an HTML table.
  • content: the markup as one JSON string, with its quotes escaped as \".
  • width (optional): the printed width in inches. Otherwise an SVG prints at its own size (96 px per inch) and a table fits its text. Up to 3.3 in fits a column; anything wider than 7.13 in is scaled down.
  • caption (optional): printed small and centred under the figure.
  • SVG:
    • One <svg> with a viewBox, or a width and height.
    • Style it with attributes or style="…", not <style> or class.
    • Fonts: Arial/Helvetica, Times or Courier only.
    • Not supported: scripts, images, links, filters or foreignObject.
  • Tables:
    • Tags: <table>, <caption>, <thead>/<tbody>, <tr>, <th> and <td>.
    • Extras: colspan/rowspan, align, and <b>, <i>, <sub>, <sup> in cells.
    • Each cell is one line, and every tag must be closed.
  • Anything that wouldn't print exactly as previewed is reported as an error. A figure no question uses is only noted.

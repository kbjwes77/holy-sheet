How to make a printable quiz with ChatGPT or Claude

A chatbot can draft a whole quiz in seconds, but its reply is just text. Here is how to get a reply you can paste straight into a free tool and print as an answer sheet, and what to check before you hand it to students.

Updated October 27, 2026

What you need

A free account with any AI chatbot (ChatGPT, Claude, Gemini or similar), and the Grade Lake free bubble sheet generator. The generator needs no sign-up. The only trick is asking the chatbot for its answer in a format the generator understands, called Test JSON.

Step by step

  1. Open the prompt builder

    Go to the free generator, choose Advanced, and open Have an AI chatbot write the questions.

  2. Describe your quiz

    Type the topic and who it is for (for example, "photosynthesis" and "9th grade biology"), then choose quiz or exam, the question style and how many questions. The prompt below the form updates as you type.

  3. Copy the prompt into a chatbot

    Press Copy prompt and paste it into ChatGPT, Claude or Gemini. The prompt includes the format rules, so the chatbot knows to answer with a single block of Test JSON and nothing else.

  4. Paste the reply back

    Copy the chatbot's whole reply and paste it into the Test JSON box. If the reply includes code fences or a friendly "Here is your quiz!", the generator removes them for you. A green message confirms the test is valid; if not, it explains the problem in plain words.

  5. Read every question

    Check the facts, the wording and, above all, the answer key. See the checklist below.

  6. Print or save a PDF

    Choose Print (US Letter, 100% scale) or Download PDF. Switch to Simple mode any time to fix a question with ordinary text boxes instead of editing JSON.

What the chatbot returns

Test JSON is plain text: a title, a type, and a list of questions with their choices and the correct letters. A one-question quiz looks like this.

{
  "test": "Photosynthesis Quiz",
  "type": "Quiz",
  "questions": [
    {
      "prompt": "Which gas do plants take in during photosynthesis?",
      "choices": ["Oxygen", "Carbon dioxide", "Nitrogen", "Hydrogen"],
      "answer": "B",
      "explanation": "Plants use carbon dioxide and water to make glucose."
    }
  ]
}

You never have to write this by hand. If you want to know every field, the Test JSON format reference lists them all.

A checklist before you print

  • Verify the answer key. Chatbots sometimes mark the wrong letter. Skim each question and confirm the highlighted answer is correct, especially in math and science.
  • Look at the spread of answers. If nearly every answer is B or C, ask the chatbot to vary which letter is correct. The prompt already requests this, but it is worth a glance.
  • Check for ambiguity. Two choices that are both defensible make a bad question. Edit them in Simple mode.
  • Watch special characters. The sheets print in a standard PDF font, so Greek letters, arrows and math symbols cannot be printed. The prompt tells the chatbot to spell them out ("delta x", "x^2", "pi").
  • Match the level. If the questions are too easy or hard, reply in the same chat ("make these harder, and use the same JSON format") and paste the new reply.

Handy follow-up requests

  • "Replace questions 3 and 7 with new ones on the same topic. Reply with the full JSON again."
  • "Add three written-answer questions at the end, each with a model answer and a rubric."
  • "Rewrite this for 6th graders, keeping the same JSON structure."

Grading the sheets

Printing is free. You can mark the sheets by hand against the answer key. If you would rather scan or photograph the finished sheets and get every score as a spreadsheet, Grade Lake Pro reads the bubbles for you. A free account keeps your tests in a library so you can print them again.

Questions, answered

Which AI chatbots work with this?

Any chatbot that can follow written instructions and reply with text, including ChatGPT, Claude and Gemini. The prompt from the generator contains the complete format rules, so you do not need to be signed in to a particular service or install anything.

What if the chatbot's reply will not load?

Paste it anyway. The generator strips code fences and chatter and checks the JSON as you type. If something is wrong it names the question and the problem, for example a missing answer or a choice with too many characters. You can fix it in Advanced mode, or paste the message back into the chatbot and ask it to correct its output.

Can the chatbot write written-answer questions too?

Yes. Choose written answers or a mix in the prompt builder. Each written-answer question comes with a model answer and an optional rubric, and prints as a writing box with the number of lines you choose.

Are the AI's answers reliable?

Not always. Treat the chatbot as a fast first draft. Read every question and check the answer key before printing, because a wrong key will mark correct student answers wrong.

Is the quiz sent to Grade Lake?

Not by the free generator. The sheet is built in your browser, and the prompt you copy goes only to the chatbot you choose to paste it into.

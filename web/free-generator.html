Test JSON format, in brief 
{
  "test": "Unit 4 Quiz",
  "type": "Quiz",
  "questions": [
    {
      "prompt": "Which of these is a prime number?",
      "choices": ["9", "15", "17", "21"],
      "answer": "C"
    },
    {
      "type": "Free Response",
      "prompt": "Explain why the sky is blue.",
      "answer": "Air scatters short (blue) wavelengths the most.",
      "lines": 4,
      "points": 2
    }
  ]
}
  • test and questions are required. type is "Quiz", "Exam" or "Study Guide".
  • A multiple-choice question has 2 to 8 choices. Give answer as letters, like "B" or "AC", on every question or on none.
  • A "Free Response" question has no choices; answer is the model answer. Optional: rubric, lines (1 to 20), points (1 to 100), explanation.
  • Graphs and tables go in a top-level figures object and are attached to a question with "figures": ["id"].
  • Don't type "A)" or question numbers into the text; the sheet adds them. Greek letters, arrows and math symbols can't be printed: spell them out.

How to make a bubble sheet

  1. Write your questions

    In Simple mode, type each question and its choices and tick the correct answers. Prefer to paste? Advanced mode takes Test JSON, including a reply from an AI chatbot.

  2. Check the preview

    The sheet updates as you type. Every question prints with lettered bubbles next to it, a name box, and a QR code that identifies the test.

  3. Print or save a PDF

    Print on US Letter at 100% scale, one copy per student. Download the PDF to share, or the test.json file to keep the test.

  4. Grade it your way

    Mark by hand with the answer key beside the preview, or upload scans to Grade Lake to get every score automatically.

Simple or Advanced

Simple mode

Boxes, sliders and buttons. Add multiple-choice or written-answer questions, tick the correct answers, set points and writing lines, and reorder or duplicate questions. It builds the Test JSON behind the scenes.

Advanced mode

Write or paste Test JSON directly, with live checking that explains any mistake in plain words. Add graphs and tables, custom instructions, and up to 256 questions. Anything you build in one mode carries over to the other.

Questions, answered

Is the bubble sheet generator really free?

Yes. Writing a test, previewing the sheets, printing them and downloading a PDF are free, with no account and no watermark. Grading scanned sheets is the only paid part: it is included in Grade Lake Pro, which costs $5 a month or $40 a year and starts with a 7-day free trial.

Do I need an account, and is my test uploaded anywhere?

No account is needed. The sheets are built in your browser, so your questions are not sent to Grade Lake while you work. The page keeps a draft in your browser's local storage so you can come back to it; clearing your browser data removes it.

Can I grade these sheets with ZipGrade or another scanner app?

No. Each sheet carries a QR code and corner marks designed for Grade Lake's grader, so other bubble-sheet apps will not read it. You can still print the sheets as a normal test and mark them by hand using the answer key shown beside the preview, or grade them in Grade Lake.

How many questions and answer choices can a sheet have?

A test can have up to 256 questions and a sheet can run to 16 pages. Multiple-choice questions take 2 to 8 choices, lettered A to H, and can have more than one correct answer. Simple mode holds up to 60 questions; use Advanced mode for more.

What paper do I print on?

Ordinary US Letter paper at 100% scale (Actual size). If your print dialog offers Fit to page or Shrink to fit, turn it off so the sheet prints at its real size. Other paper sizes are not supported yet.

Can students write free-response answers?

Yes. A written-answer question prints a full-width writing box with the number of lines you choose, from 1 to 20. Grade Lake Pro can read the handwriting with an AI model and grade it against your model answer and rubric; on the free generator you can print the box and mark it yourself.

What is Test JSON, and can ChatGPT or Claude write my test for me?

Test JSON is the plain-text format Advanced mode reads: a test name and a list of questions with their choices and answers. Advanced mode includes a prompt builder that teaches an AI chatbot such as ChatGPT, Claude or Gemini the format, so you can ask it for a whole quiz, paste the reply in, and print it. Read the questions before you print, because chatbots sometimes get an answer wrong.

Can I add graphs, diagrams or tables to questions?

Yes, in Advanced mode. Define each figure once as an SVG drawing or an HTML table and attach it to any question. Figures print the same in the preview and in the PDF. Simple mode keeps figures you add in Advanced but cannot edit them.

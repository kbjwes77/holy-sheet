Test JSON format reference

Test JSON is the plain-text format Grade Lake uses to describe a test: a title, a list of questions, their choices and the correct answers. You can write it by hand, have an AI chatbot write it, or let the free generator build it from boxes and sliders.

Updated October 27, 2026

A complete example

This test has one multiple-choice question and one written-answer question that uses a table.

{
  "test": "Unit 4 Quiz",
  "type": "Quiz",
  "instructions": "Answer every question. Show your work on the back.",
  "columns": 2,
  "figures": {
    "prices": {
      "type": "table",
      "content": "<table><tr><th>Price</th><th>Quantity</th></tr><tr><td>$2</td><td>100</td></tr></table>",
      "caption": "Figure 1"
    }
  },
  "questions": [
    {
      "prompt": "Which of these is a prime number?",
      "choices": ["9", "15", "17", "21"],
      "answer": "C",
      "points": 1,
      "explanation": "17 has no divisors other than 1 and itself."
    },
    {
      "type": "Free Response",
      "prompt": "Using the table, what is the quantity at a price of $2?",
      "figures": ["prices"],
      "answer": "100",
      "rubric": "1 point: reads 100 from the table.",
      "points": 2,
      "lines": 2
    }
  ]
}

Test fields

FieldTypeRequiredWhat it does
testtextYesThe title printed on the sheet (up to 200 characters).
typetextNo"Quiz", "Exam" or "Study Guide". A study guide has no bubbles and is not graded.
questionslistYesThe questions, in order. Up to 256 per test; a test can print at most 16 pages.
figuresobjectNoGraphs (SVG) and tables (HTML) defined once and referenced by id from questions.
instructionstextNoA line of instructions printed on the sheet.
columnsnumberNo1 for single-column layout; the default is two columns.

Question fields

FieldTypeRequiredWhat it does
prompttextYesThe question text. Do not type question numbers; the sheet numbers them.
choiceslistMultiple choice2 to 8 plain-text choices. Letters A to H are added when printed, so do not start choices with "A)" or "1.".
answertextAll or noneMultiple choice: the correct letters, such as "C" or "AC" when two are correct. Written answer: the model answer.
typetextWritten answer"Free Response" makes a written-answer question, which has no choices.
pointswhole numberNo1 to 100; the default is 1.
rubrictextNoWritten answers: what earns each point.
lineswhole numberNoWritten answers: writing lines in the answer box, 1 to 20; the default is 3.
explanationtextNoWhy the answer is correct. Printed as a solution on study guides and teacher copies.
figureslist of idsNoThe ids of figures this question uses.

Rules that matter

  • Answers are all or none. Either every question has an answer or none does. A test with answers can be graded; a test without prints as a plain worksheet.
  • Written answers need a model answer unless the test is a Study Guide.
  • Choices are plain text. No letters or numbers at the start, no question numbers in prompts.
  • Limits. 2 to 8 choices per question, up to 256 questions, up to 2,000 characters in any text field, and at most 16 printed pages.
  • Quotes and commas. Use straight quotes, escape quotes inside text as \", and no trailing commas or comments.

Figures: graphs and tables

Define each figure once in the top-level figures object and list its id in the question's figures array. A figure has a type of "svg" or "table", the content as one JSON string, and an optional width in inches and caption. SVGs must be self-contained: one <svg> with a viewBox, attributes for styling, standard fonts (Arial, Times or Courier), and no scripts, images, links or filters. Tables may use table, caption, thead, tbody, tr, th and td.

Characters that cannot be printed

Sheets print in a standard PDF font. Letters, digits, keyboard punctuation, accented Latin letters and a few symbols (° ± × ÷ ² ³ ¼ ½ ¾ µ ¢ £ € § ¶ © ® ™ « » ¿ • – — … and curly quotes) are fine. Greek letters, arrows, math symbols such as ≤ ≥ ≠ √ ∞, other superscripts and subscripts, and emoji are not. Spell them out: "delta x", "pi", "<=", "x^4", "H2O", "sqrt(x)".

Common errors

  • "JSON syntax: Unexpected end": the text was cut off. Copy the whole reply, including the final closing brace.
  • A question is missing its answer: add an answer to every question or remove them all.
  • Too many choices: a question can have at most 8.
  • A character that cannot be printed: replace symbols with words, as above.

Questions, answered

What is Test JSON?

Test JSON is the plain-text format Grade Lake reads to describe a test: a title, an optional type, and a list of questions with choices and answers. It is standard JSON, so any text editor or AI chatbot can write it.

Do I have to write Test JSON myself?

No. The free generator's Simple mode builds it from text boxes, sliders and buttons, and its AI helper creates a prompt that makes a chatbot write it for you.

How many questions can a test have?

Up to 256 questions, as long as the printed test fits within 16 pages. Multiple-choice questions can have 2 to 8 choices.

Can a question have more than one correct answer?

Yes. List every correct letter in the answer, for example "AC", and tell students to select all that apply.

Why can't I use Greek letters or arrows?

Sheets print in a standard PDF font that does not include them. Spell them out, for example "delta x" or "x^2", or draw them in an SVG figure.
